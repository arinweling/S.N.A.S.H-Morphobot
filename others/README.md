## 🔧 Future Work

The Morphobot project has reached a significant milestone, but there are several exciting directions for future development:
---

### Future Work
- Improve flange bearing support to enhance wheel stability during movement.  
- Enable independent servo control using additional PWM pins for precise leg alignment.  
- Optimize power distribution by evaluating servo current needs and consolidating buck converters.  
- Add features like FPV camera, GPS, and companion computer for autonomy and real-time feedback.  
### Learnings and takeaways
### Things Learned the Hard Way
- Team management, communication, and clear work allotment are key to project success.  
- Proper measurements, simulations, and testing are essential to avoid costly design errors.  
- Time management is crucial, balancing the project with other commitments and deadlines.  

### Things Learned the Easy Way
- Passion for the project kept us motivated and driven throughout.  
- Research, clear understanding, and communication within the team are critical for project success.
